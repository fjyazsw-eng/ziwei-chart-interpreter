# 大限与流年分析

## 分层原则

时间分析固定为：

1. 本命：长期存在的能力、需求与矛盾；
2. 大限：十年内被放大的生活领域和主要课题；
3. 流年：该十年主题在某一年的触发位置；
4. 现实条件：年龄、职业阶段、关系状态和用户已知事件决定具体表现。

不得跳过本命和大限，直接用流年四化断事。

## 大限步骤

- 确认公历年份、虚岁、大限宫位与大限四化；
- 读取大限宫本命结构及其三方四正；
- 比较大限四化与生年四化是否加强、转移或形成张力；
- 输出十年主题、机会来源、主要代价和可验证阶段，不把十年写成一个连续吉凶标签。

## 流年步骤

- 确认流年命宫和流年四化；
- 检查是否触及用户主题的宫位网络；
- 检查是否重复激活本命或大限的禄、权、科、忌结构；
- 只在多层信号汇聚时标记为高关注年份；
- 说明关注领域和可能表现，不声称必然事件。

## 年份分级

- **高关注**：本命主题、大限宫位和流年触发三层汇聚。
- **中关注**：两层支持，或机会与制约明显并见。
- **一般观察**：只有孤立流年信号，缺少本命与大限承接。

年份等级不是吉凶等级。高关注可以意味着机会、压力或重要选择。

## 长周期请求

用户要求分析十年或更多年份时：

1. 先给每个大限的总主题；
2. 再列高关注与中关注年份；
3. 一般观察年份合并说明；
4. 不强行让每年都有重大事件。

若用户明确要求逐年表格，可以逐年输出，但对证据不足的年份写“一般观察”，不填充故事。
