# 大限与流年分析

计算与校验流程保持完整。以下“读取、记录、建立、分析”均为内部要求；对外按 [输出规范](output-template.md) 默认只给总体评价、重要窗口/注意事项和建议，教学时再展开对应依据。

## 分层原则

时间分析固定为：

1. 本命：长期存在的能力、需求与矛盾；
2. 大限：十年内被放大的生活领域和主要课题；
3. 流年：该十年主题在某一年的触发位置；
4. 流月：在已成立的年度主题中进一步聚焦；
5. 流日：对短期状态与行动节奏做微调；
6. 现实条件：年龄、职业阶段、关系状态和用户已知事件决定具体表现。

不得跳过本命和大限，直接用流年四化断事。

## 强制时间层事实表

任何涉及某一大限、某一年或若干年份的问题，解释前必须先建立 `TIME_LAYER_FACT_TABLE`：

1. 本命层：宫位、地支、原局星曜、生年四化、自化/向心化；
2. 大限层：十二大限宫、地支、叠入本命宫、原局星曜、大限四化；
3. 流年层：十二流年宫、地支、叠入本命宫、叠入大限宫、原局星曜、流年四化。

若问题精确到月日，再扩展：

4. 流月层：目标日期、农历月与闰月状态、流月命宫、十二流月宫、叠入前三层、月干与流月四化；
5. 流日层：农历日、流日命宫、十二流日宫、叠入前四层、日干与流日四化。

表格是内部计算底盘，不必默认全文展示。时间层未完成或闭环未通过，不得进入专题解释。

## 大限步骤

- 确认公历年份、虚岁、大限宫位与大限四化；
- 软件未展开大限十二宫时，以大限命宫地支为锚点，按确定性推导规则生成大限十二宫叠本命表；
- 读取大限宫本命结构及其三方四正；
- 读取用户主题对应的大限同名宫及其三方四正，不能只读大限命宫；
- 比较大限四化与生年四化是否加强、转移或形成张力；
- 输出十年主题、机会来源、主要代价和可验证阶段，不把十年写成一个连续吉凶标签。

## 流年步骤

- 确认流年命宫和流年四化；
- 若软件给出流年命宫地支但未展开流年十二宫，先按下述固定算法完成宫位叠映；
- 检查是否触及用户主题的宫位网络；
- 检查是否重复激活本命或大限的禄、权、科、忌结构；
- 只在多层信号汇聚时标记为高关注年份；
- 说明关注领域和可能表现，不声称必然事件。

## 由运限命宫派生十二宫

大限和流年共用同一套宫位叠映算法。仅当软件明确给出目标大限或年份的命宫地支，且本命十二宫地支完整、唯一时使用。该过程是坐标叠映，不是重新安星。

1. 将地支编码为：子0、丑1、寅2、卯3、辰4、巳5、午6、未7、申8、酉9、戌10、亥11。
2. 令软件给出的运限命宫地支索引为 `m`。
3. 按固定宫序建立运限宫：命、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母。
4. 上述宫序第 `k` 项所在的地支索引为 `(m - k) mod 12`，其中流年命宫的 `k=0`。
5. 将每个运限宫落到同一地支的本命宫，读取该位置的软件原始星曜，形成“运限宫叠本命宫”事实表。
6. 检查十二地支各出现一次、无重复缺失、相邻宫严格逆行一位；流年层还要按物理地支叠入当前大限宫。

例如软件给出流年命宫在午，则流年兄弟在巳、流年夫妻在辰、流年子女在卯，依次类推。输出时标为“确定性派生”，不得假称软件已列出这些运限宫。

派生后，专题分析固定读取：

- 流年命宫及其三方四正；
- 用户主题对应的流年宫及其三方四正；
- 这些流年宫分别叠入哪些本命宫和大限主题；
- 流年四化落入的本命地支位置，并判断是否进入上述流年宫网络；
- 同一颗四化星必须在内部同时记录本命宫、大限宫和流年宫三个坐标；教学涉及该星时按需展示，不能混淆层级；
- 限、流同宫或同一主题重复激活时才提高关注等级。

宫位决定年度事件的落点，四化描述动力与阻力，两者必须交叉使用。不能只把流年四化落到本命宫就声称完成完整流年分析。

特别区分四个概念：本命专题宫、大限专题宫、流年专题宫、本命专题宫内星曜被时间四化激活。后者不自动等于流年同名宫发生四化。

### 派生边界

可以派生的是大限/流年十二宫标签、与本命宫位的叠映，以及符合规则配置的十干四化。不得因此补出：

- 软件未给出的流昌流曲、流魁流钺、流羊流陀等流曜；
- 软件未给出的飞化路径、宫干四化或其他流派动态规则；
- 年界、闰月或排盘口径修正；软件给出的目标年份和流年命宫必须作为起点。

四化缺失时按 [确定性推导](derivation-rules.md) 的兼容性检查处理。命宫锚点缺失、冲突或不能唯一定位时，明确标注“简化运限分析”，降低具体事件与时间判断的置信度。

正式输出前执行 [时间盘质检与回归](time-qa.md)。

## 流月与流日

涉及具体月份或日期时必须读取 [流月与流日补全](month-day-rules.md)。按 M0 软件完整直出、M1 软件锚点补全、M2 标准公式推导的顺序选用最高可用来源。农历、斗君变量、闰月、相关边界和月日干支均可确定时，M2 即可正式补全和解读；不要求先取得软件流月/流日锚点。

当用户问某月、最佳月份或某月关键日期时，若 M2 条件齐全，必须继续生成相应流月/流日十二宫与四化并建立五层叠宫，不能仅因 TXT 缺少软件月日锚点而停在流年。输出标记 M2 未经文墨天机锚点复核；若决定计算结果的变量缺失或矛盾，才停止对应层并列出缺项。

分析次序不可改变：本命 → 大限 → 流年 → 流月 → 流日。月日层用于聚焦主题和安排复核，不独立决定重大事件。流日不宜用于“趋吉避凶”的保证式承诺；现实中的合同、医疗、交通和财务决定仍依赖专业检查与实际条件。

## 年份分级

- **高关注**：本命主题、大限宫位和流年触发三层汇聚。
- **中关注**：两层支持，或机会与制约明显并见。
- **一般观察**：只有孤立流年信号，缺少本命与大限承接。

年份等级不是吉凶等级。高关注可以意味着机会、压力或重要选择。

## 长周期请求

用户要求分析十年或更多年份时：

1. 先给每个大限的总主题；
2. 再列高关注与中关注年份；
3. 一般观察年份合并说明；
4. 不强行让每年都有重大事件。

若用户明确要求逐年表格，可以逐年输出，但对证据不足的年份写“一般观察”，不填充故事。
