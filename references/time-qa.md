# 时间盘质检与回归

凡涉及大限、流年或年份专题，在解释前执行本检查。完整表可以只保留在工作底盘中；用户要求校验时再展示。

## ZIWEI_TIME_QA

### 时间层

- 大限、流年命宫锚点均来自软件直出或明确标注的确定性规则；
- 目标时间层十二宫齐全，宫序为命、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母；
- 十二地支各出现一次，无重复、无缺失、无跳位；
- 流年十二宫分别正确叠入本命宫与当前大限宫；
- 任一锚点冲突或闭环失败时停止专题解释，先纠正或降级为简化分析。

若含流月、流日，追加：

- `MONTH_DAY_CONFIG` 已记录软件版本、时区、目标公历/农历日期、年界、月界和闰月规则；
- 流月命宫来自软件直出、软件正月锚点顺推，或通过已核验的斗君公式；
- 流日以目标流月命宫为初一顺行，跨月后已重新起算；
- 流月、流日十二地支各出现一次，且分别正确叠入本命、大限、流年及上一级；
- 目标日期在边界附近时已经检查边界两侧；闰月至少检查十五日前后；
- 软件锚点与公式不一致时已停止自动补全并报告差异。

### 专题与四化

- 已读取本命、大限、流年三层同名专题宫及各自三方四正；
- 每个关键四化都记录星曜物理地支、本命宫、大限宫、流年宫；
- 未把“本命某宫星曜被流年四化激活”误写成“流年同名宫化曜”；
- 四化来自软件直出或已通过兼容性检查的十干表；无法定位的星曜标记缺失，不猜位置。
- 流月四化来自目标月干，流日四化来自目标日干；月日干支来源可追溯，并已投影到全部已建立时间层。

### 结论

- 重要结论不是单星、单宫或单一四化定论；
- 宫位主题没有被直接等同于唯一现实事件；
- 没有通过流月或流日补全校验时不精确到月、日或周；
- 清楚区分 `FACT`、`DERIVED`、`INTERPRETATION`；
- A/B/C 表示证据层级，不表示事件发生概率。

关键项失败时不得带着错误坐标继续解释。

## 流月流日回归用例

输入：流年命宫午、出生农历八月、出生时支子、目标农历八月初五、非闰月、同月规则。

必须得到：流月命宫午、流日命宫戌；流月夫妻宫辰、流日夫妻宫申。若初五仍停在午或从上月连续累计，判定失败。

闰月分段测试：相同输入改为闰六月，采用十五日分段规则。十五日与十六日的流月命宫必须顺行一宫；采用同月规则时两日流月命宫必须相同。任何结果都必须显示所用规则，不能只给宫位。

## 2026 回归用例

输入锚点：流年命宫为午。按 `(m-k) mod 12` 派生后必须得到：

| 流年宫 | 地支 |
|---|---|
| 命 | 午 |
| 兄弟 | 巳 |
| 夫妻 | 辰 |
| 子女 | 卯 |
| 财帛 | 寅 |
| 疾厄 | 丑 |
| 迁移 | 子 |
| 交友 | 亥 |
| 官禄 | 戌 |
| 田宅 | 酉 |
| 福德 | 申 |
| 父母 | 未 |

必须通过：流年夫妻=辰、官禄=戌、田宅=酉、疾厄=丑。若官禄被排为酉，判定失败并重算。

若丙年四化星曜物理位置为天同酉、天机丑、文昌申、廉贞午，则流年坐标必须分别为田宅、疾厄、福德、命。天机本命坐夫妻而当年化权，应写成“本命夫妻主题被激活，且该星所在物理位置在当年对应流年疾厄”，不得写成“流年夫妻宫天机化权”，除非派生结果确实如此。
