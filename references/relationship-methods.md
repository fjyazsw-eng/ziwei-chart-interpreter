# 感情、恋爱应期与配偶衍生宫

本文件用于感情婚姻、正缘画像与恋爱时间专题。先遵守 [证据与冲突裁决](evidence-rules.md)；宫位衍生只提供观察角度，不把对方的现实身份、品质或行为写成既定事实。

## 恋爱三宫联动

把感情过程拆成三个互相制约的环节：

1. **子女宫：遇见与吸引**。观察桃花来源、初始接触、选择空间与互动启动条件，不直接等于“桃花质量好坏”。
2. **夫妻宫：关系形成与相处**。观察进入关系的意愿、伴侣期待、互动模式与承诺议题。
3. **福德宫及财福线：经营与承压**。福德宫观察内在满足、情绪容量和持续投入；财帛—福德轴可辅助观察时间、精力、金钱与安全感如何影响关系。

三宫分别回答“遇不遇得到、能不能形成、能不能经营”。任何一宫不能单独证明恋爱、结婚或分手。

### 组合读取

- 子女宫较顺、夫妻宫受制：可能容易认识或被吸引，但关系确认、磨合或承诺较费力。
- 夫妻宫较顺、子女宫受制：可能有关系意愿或相处能力，但可选择对象、接触机会或初期吸引不足。
- 夫妻宫较顺、福德或财福线受制：可能能开始关系，但长期投入、情绪调节、价值排序或资源分配成为课题。
- 福德或财福线较顺、子女宫受制：可能愿意经营，却需要防止因投入意愿强而忽略对象适配度。
- 三者同向且大限、流年承接：才提高为较值得关注的关系窗口；仍须结合现实关系状态。

所谓“同相四化”只可作为辅助结构：两个相关宫位分别受到相近性质的禄、权、科或忌激活，且来源、物理地支和时间层都可定位。它不是独立公式，不允许由“同化”直接断恋爱发生。宫干飞化、自化互引只有在软件明确给出路径和箭头定义时才使用。

### 恋爱应期

按以下顺序判断：

1. 本命三宫是否具备关系需求、接触渠道与经营能力；
2. 当前大限是否放大夫妻、子女、福德或相关三方四正；
3. 流年是否再次触发至少两个相关环节；
4. 四化是否进入同一专题网络并形成重复激活；
5. 流月、流日仅用于缩小已经成立的年级窗口，不反向创造本命和大限没有承接的事件。

“容易恋爱”与“适合投入”要分开表达。前者指接触与关系启动信号增多；后者还需相处、经营、现实边界和对方实际情况共同支持。

## 夫妻宫立太极

以本命夫妻宫作为“配偶命宫”，按十二宫相对次序建立配偶衍生十二宫：

| 配偶衍生宫 | 命主本命宫位 | 可观察主题 |
|---|---|---|
| 配偶命宫 | 夫妻宫 | 命主所体验到的对方气质、关系角色 |
| 配偶兄弟宫 | 子女宫 | 对方同辈、手足与近身协作环境 |
| 配偶夫妻宫 | 财帛宫 | 对方在伴侣关系中的互动与价值交换 |
| 配偶子女宫 | 疾厄宫 | 对方对子女、照料、创造与亲密议题的倾向 |
| 配偶财帛宫 | 迁移宫 | 对方的求财方式、资源流动与外部机会 |
| 配偶疾厄宫 | 交友宫 | 对方的身体与压力象义，仅作宽泛提醒 |
| 配偶迁移宫 | 官禄宫 | 对方的外部发展、行动平台与异地议题 |
| 配偶交友宫 | 田宅宫 | 对方社交网络与圈层环境 |
| 配偶官禄宫 | 福德宫 | 对方事业模式、责任感与长期投入 |
| 配偶田宅宫 | 父母宫 | 对方家庭、居住与固定资源背景 |
| 配偶福德宫 | 命宫 | 对方在关系中呈现的精神需求与情绪模式 |
| 配偶父母宫 | 兄弟宫 | 对方父母、长辈支持及家庭规范 |

### 使用限制

- 这是从命主盘面观察“关系中的对方角色”，不是对方本人的独立命盘；若要判断对方真实人生结构，应读取对方命盘或现实资料。
- 配偶家境宜综合配偶父母、田宅及其三方四正；配偶事业与财务宜综合配偶官禄、财帛、迁移；外形只可描述宽泛气质，不给确定颜值、身高或身体尺寸。
- “正缘”应先向用户确认含义。默认解释为更可能进入稳定、正式关系的一类对象，不把领证、幸福或唯一对象写成命定事实。
- 不由单一权忌、煞曜或飞化断家暴、出轨、成瘾、疾病、性能力或道德品质。现实中已有暴力、胁迫或安全威胁时，现实证据优先，并建议寻求可信支持和专业帮助。
- 配偶画像至少需要两个衍生宫位与夫妻宫主轴相互支持；仅有一个衍生宫时为 C 级提示。

## 输出建议

正缘画像应按“关系气质—事业与资源—家庭与社交—相处课题—待现实验证”组织。每一项注明主要宫位、反向证据和置信度，避免列出貌似精确但无法验证的身份清单。
