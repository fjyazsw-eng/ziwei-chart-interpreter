# 确定性推导

只补全由软件已给事实和显式规则唯一确定的时间叠层。把本命盘视为不可变底盘；大限、流年、流月和流日是覆盖在同一十二地支坐标上的独立层，不移动、不复制本命星曜。

## 优先级与来源

1. 软件直出优先；
2. 软件缺失时才使用规则派生；
3. 派生结果标注规则名称、输入变量及可用的软件锚点；没有软件月日锚点的 M2 另标未复核状态；
4. 软件与规则冲突时保留两者，以软件为分析口径并停止同类自动派生；不允许为了维持前文结论而沿用错误坐标。

规则名称、配置和输入在内部完整保留；对外展示遵守 [输出规范](output-template.md)，M2 必需未复核标记不得省略。教学或校验时提供相关计算摘要。

内部标签固定为：`FACT`（软件或用户明确给出）、`DERIVED`（由选定规则唯一得到）、`INTERPRETATION`（术数解释）。解释不得反写成事实。

## 宫位叠层

大限或流年给出命宫地支时，使用 [时间分析](timing-rules.md) 的固定十二宫算法派生整层宫位。每个物理地支同时记录：

- 本命宫名与本命星曜；
- 当前大限宫名；
- 目标流年宫名；
- 生年、大限、流年四化激活。

每个关键四化统一记录为：`四化星 → 物理地支 / 本命宫 / 大限宫 / 流年宫 / 流月宫 / 流日宫`，只填写已建立的时间层。物理位置不随时间移动，改变的是该地支在不同时间层的宫名。

专题分析读取相应层的同名宫及三方四正，不用“流年命宫叠入某本命宫”代替完整流年宫位网络。

## 不能自动补全

- 由出生资料重排本命十二宫、星曜或亮度；
- 软件未给且无已选规则的宫干飞化、自化或飞宫路线；
- 流昌流曲、流魁流钺、流羊流陀等动态流曜；
- 未确定会影响目标层的年界、月界、农历月/日、出生农历月、出生时支、流年命宫或闰月规则时的流月、流日；
- 不同流派的四化、年界、闰月和岁数口径静默切换；
- 仅凭文章口诀或模型记忆完成公历农历换算、月柱或日柱。

需要这些能力时，先取得对应软件直出数据、可靠历法数据或由用户明确指定配置，不静默套用另一套体系。M2 必要变量齐全且无不可消除歧义时，流月、流日宫位和十干四化属于允许正式解读的确定性派生，不强制先有软件月日锚点；输出须标“公式推导盘｜未经文墨天机流月/流日锚点复核”。
