# 流月与流日补全规则

本文件只在用户询问流月、流日、具体月份或具体日期时读取。目标是优先复现文墨天机等软件的显示口径；软件直出高于公式补全。

## 支持等级

1. **M0 完整直出**：软件给出目标公历日期、对应农历日期、是否闰月、流月/流日命宫、月日干支及四化。直接使用并校验十二宫闭环。
2. **M1 锚点补全**：软件给出流年命宫、正月或目标流月命宫、目标农历日期中的必要锚点；只补全能由锚点唯一确定的部分。
3. **M2 斗君公式补全**：缺少流月命宫，但出生农历月、出生时支、目标流年命宫、目标农历月日与闰月规则均明确。使用下述公式，并至少与同一软件的一组已知流月或流日位置核验。
4. **M3 简化分析**：年界、月界、闰月、日期换算或干支不明确。停在已知层，不精确到月日。

文墨天机优先兼容的含义是：以用户提供的文墨天机截图/TXT、版本和设置作为口径锚点；没有软件锚点时，不声称公式结果就是文墨天机直出。

## 必需输入

补全前建立 `MONTH_DAY_CONFIG`：

- 排盘软件、版本（若可得）及流派/四化表设置；
- 本命十二地支坐标；
- 出生农历月 `1..12`、是否闰月、出生农历日；
- 出生时支；早子/晚子只影响日期归属时还须记录软件设置，斗君本身均按子支处理；
- 目标公历日期和时区；
- 软件或可靠历法转换得到的目标农历年、月、日、是否闰月；
- 流年命宫地支；
- 年界：`农历正月初一` 或 `立春`；
- 月界：`农历初一` 或 `节气`；
- 闰月规则：`同月不另进一宫`、`十五日分段` 或 `软件直出锚点`；
- 目标月干、日干，或可复核的月柱、日柱；
- 至少一个文墨天机已显示的正月/目标月/目标日命宫，供兼容性核验。

凡日期换算或边界设置不明确，先请求截图或导出，不靠记忆换算农历。

## 坐标与斗君公式

地支编码固定为：子0、丑1、寅2、卯3、辰4、巳5、午6、未7、申8、酉9、戌10、亥11。

令：

- `Y` = 目标流年命宫地支索引；
- `B` = 出生农历月数；
- `H` = 出生时支索引；
- `T` = 目标农历月数。

普通月份下，正月命宫（流年斗君）为：

`M1 = (Y - B + H + 1) mod 12`

目标流月命宫为：

`M = (Y - B + H + T) mod 12`

这等价于：从流年命宫起正月，逆数至出生月，再从该宫起子时顺数至出生时，所得为正月；随后各月顺行一宫。

### 闰月

闰月没有跨流派唯一口径，必须显式选择：

- **同月规则**：闰月沿用同名月的流月命宫，`T` 不加一。
- **十五日分段规则**：闰月初一至十五按同名月，十六日至月底按下一月；即后半月 `T_effective = T + 1`。若命主出生于闰月且使用同一分段规则，出生闰月十六日后 `B_effective = B + 1`。
- **软件锚点规则**：直接采用软件显示的流月命宫；公式只用于解释和交叉验证。

不得把一种闰月规则静默替换成另一种。闰月前后至少各验一个日期。

## 流日

确定目标流月命宫索引 `M` 后，农历初一为该月流日命宫；按日顺行：

`D = (M + lunar_day - 1) mod 12`

再以 `D` 为命宫锚点，按固定宫序逆行派生流日十二宫。跨农历月时必须先切换新的流月命宫，不能把上月日序连续累加。

## 十二宫与叠层

流月、流日和大限、流年使用同一固定宫序：命、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母。

目标层命宫索引为 `m` 时，第 `k` 宫地支为 `(m-k) mod 12`。每一物理地支同时记录本命、大限、流年、流月、流日宫名；本命星曜不移动。

## 年界、月界与农历

- 年初必须记录软件采用农历正月初一还是立春换年。目标日期落在两者之间时，两套结果可能不同，未经确认不得自动选择。
- 目标月若软件采用节气分界，不能把农历月数直接代入农历流月公式；应使用软件直出流月命宫和月干支，或切换到与软件一致的历法引擎。
- 公历转农历、大小月、闰月和日柱属于历法数据问题。Skill 不凭心算补造，必须来自软件直出或可标明版本的可靠历法工具。
- 晚子时导致的日期归属按软件设置处理；目标日柱和农历日可能随设置变化。

## 流月、流日四化

- 流月四化取**目标月天干**，流日四化取**目标日天干**；优先使用软件直出的月柱、日柱与四化。
- 软件只给天干时，可在通过兼容性检查后使用 [确定性推导](derivation-rules.md) 的十干四化表。
- 每颗四化星定位到本命盘的物理地支，再同时投影到本命、大限、流年、流月、流日宫名。
- 流月、流日四化是时间激活，不是新增星曜；不自动补流昌流曲、流羊陀等动态流曜。
- 月日四化只用于缩小已成立主题的观察窗口。孤立的流日化忌不能支撑破财、争吵、事故、疾病或合同失败等具体事件。

## 分析顺序

固定为：本命承接 → 大限放大 → 流年触发 → 流月聚焦 → 流日微调 → 现实条件。流日主要用于安排复核、沟通、准备和风险控制，不用于保证结果。

## 实现与来源说明

可用 `scripts/derive_month_day.py` 生成可复核的宫位与四化坐标。脚本不负责公历农历换算，也不猜年界、闰月或月日干支。

斗君与流日公式可与传统“太岁逆数生月、顺数生时；流月宫起初一顺数”的规则交叉验证。开源排盘库 iztro 2.6.0 的实现也采用等价索引，并把闰月十五日分段设为可选处理；其官方文档同时明确流月对象包含 `isLeapMonth`、`part` 和日期区间。该实现仅作公开算法参照，不能替代文墨天机直出锚点：

- https://github.com/SylarLong/iztro/blob/main/src/astro/FunctionalAstrolabe.ts
- https://github.com/SylarLong/iztro-docs/blob/main/type-definition.md
