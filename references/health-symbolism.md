# 健康象义参考库

本文件只在健康、压力或生活管理专题中读取。它保存传统象义的检索词，不提供医学诊断、病因判断、寿命推断或治疗建议。

## 安全边界

- 先看疾厄宫及三方四正，再看命宫、福德宫、长期生活方式与运限；单星、单宫、单一四化均为 C 级。
- 星曜身体象义只可写成“传统象义提示关注某类系统或体验”，不得写成“患有、会得、遗传了”具体疾病。
- 禄权科忌在健康专题中表示不同形式的激活或负荷，不统一视为吉或凶：禄可联想到增加与摄入，权可联想到紧张与负荷，科可联想到持续与反复，忌可联想到阻滞与不适；这些都不是医学机制。
- “手术、肿瘤、性传播疾病、抑郁、自杀、残疾、寿命”等高风险结论不得由术数推断。若用户报告症状、异常指标或自伤念头，停止命理定性，建议及时联系合格医疗或紧急支持。
- 运限只用于提示何时更应注意休息、复查或生活管理，不把某月某日写成发病日。

## 宽泛象义索引

下表用于生成低确定性的关注方向。实际输出通常只选择与多重结构重复出现的 1 至 3 项。

| 星曜 | 可用的宽泛象义词 | 不可直接推出 |
|---|---|---|
| 紫微、天府、天梁 | 消化、吸收、代谢与恢复节律 | 胃病、糖尿病或寿命 |
| 天机 | 神经紧张、睡眠、筋骨与四肢劳损 | 神经疾病、骨折 |
| 太阳 | 精力消耗、眼部、头部与循环负荷 | 高血压、心脑血管疾病 |
| 武曲 | 呼吸、皮肤、鼻部与紧绷感 | 肺病、手术 |
| 天同 | 免疫体验、消化、泌尿与生活习惯 | 免疫疾病、肥胖 |
| 廉贞 | 炎症、循环、皮肤与生殖泌尿关注 | 血液病、性传播疾病 |
| 太阴 | 睡眠、体液代谢、泌尿与生殖关注 | 肾病、妇科疾病 |
| 贪狼 | 作息、饮酒应酬、肝胆与生殖泌尿负荷 | 性病、纵欲或成瘾 |
| 巨门 | 口腔、咽喉与消化道体验 | 肿瘤或特定胃肠病 |
| 天相 | 循环、体液、皮肤与平衡感 | 血压病或过敏诊断 |
| 七杀、破军 | 急性消耗、碰撞风险、恢复与重建 | 必然外伤或手术 |

辅煞只修正“波动、紧张、意外暴露、恢复成本”等程度，不直接命名疾病。空劫也不得被写成“有它反而没大病”。

## 结构化读取

1. **长期底盘**：疾厄宫主星、状态、三方四正、生年四化；判断的是身体管理模式，不是疾病清单。
2. **心理压力**：命宫与福德宫同时受制时，可提示压力、睡眠或情绪调节负担；不得自行诊断抑郁或自伤风险。
3. **累积与触发**：本命有宽泛倾向、大限持续放大、流年再次触发时，可提高“健康管理关注度”；没有症状不推断患病。
4. **现实校验**：只询问已有症状、体检结果、作息、压力和就医情况；不得利用用户反馈倒推一个具体病名。

## 推荐措辞

可写：“传统象义在消化与作息管理上出现重复提示；如果现实中已有持续不适，以医生检查为准。”

不可写：“这个组合就是糖尿病”“某年会开刀”“化忌代表恶化”“某星说明有性病”。
