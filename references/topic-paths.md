# 专题分析路径

只加载用户关心的路径；相关宫位必须放回三方四正与本命四化中理解。以下是内部分析路径，不是默认输出目录；对外统一用 [三档输出](output-template.md)，只呈现当前问题的定性、重要表现、应期/注意事项与建议。

只要专题含时间范围，先建立完整时间层事实表，再强制调用本命、大限、流年三层同名专题宫及各自三方四正。不能用“流年命宫叠本命专题宫”替代真正的流年专题宫。

## 事业与学业

官禄宫 → 官禄三方四正 → 命宫的能力与行动模式 → 财帛宫的变现方式 → 迁移宫的平台与环境 → 福德宫的持续动力 → 四化与运限。

输出职业环境、工作方式、优势、瓶颈、适合的能力建设。没有行业级证据时，不列唯一职业。

## 财务

财帛宫 → 命财官迁主轴 → 田宅宫 → 福德宫的安全感和消费动力 → 禄忌与煞曜 → 当前运限。

区分赚钱方式、现金流体验、守成方式和风险偏好。不得预测收益、资产数字或给投资指令。

## 感情与婚姻

夫妻宫 → 夫妻三方四正（夫妻、官禄、迁移、福德）→ 子女宫的接触与吸引 → 福德宫/财福线的经营能力 → 命宫互动方式 → 交友宫环境 → 四化与运限。

输出关系需求、沟通模式、容易出现的张力及改善条件。不得由单一煞忌断离婚、外遇或配偶遭遇。

感情、正缘画像或恋爱应期必须读取 [感情与配偶衍生宫](relationship-methods.md)。区分“容易启动关系”与“适合投入”；子女、夫妻、福德三宫的任何单一信号都不能独立断恋爱。询问配偶画像时可由夫妻宫立太极，但衍生宫只描述命主盘中所见的关系角色，不替代对方命盘。

## 人际与合作

交友宫 → 交友三方四正 → 命宫 → 兄弟宫 → 官禄宫 → 四化与当前运限。

区分私人关系、同辈支持、职场合作和资源网络。

## 居住与家庭

田宅宫 → 田宅三方四正 → 父母、夫妻、子女相关结构 → 迁移宫 → 运限。

空宫必须借对宫及三方判断，不能解释成“没有房产”或“没有家庭缘”。

## 健康与压力

疾厄宫 → 疾厄三方四正 → 命宫与福德宫 → 煞忌 → 运限。

仅描述压力模式、生活管理倾向和需要留意的宽泛领域。不得诊断疾病、推断寿命或建议停止医疗。

健康专题必须读取 [健康象义参考库](health-symbolism.md)。星曜—身体对应只作为 C 级检索词；只有本命结构、长期运限和现实状态重复支持时，才能提高“关注度”，仍不得命名疾病或发病时间。

## 整体初读

仅在用户明确问整体、综合、全盘或十二宫时使用；仅上传命盘用接盘模式。

内部综合资料口径、命身与核心宫位、主要结构、性格与压力反应、优势与长期课题、当前大限及可靠时间窗口。默认对外先给总体定性，再取最重要的少量情况、注意点与建议；不自动附资料完整度、十二宫清单或下一步菜单。

用户明确要求十二宫或逐宫时才逐宫给简明结果，空宫结合对宫和三方；不因此自动进入教学模式。问某年整体时内部完成时间层与相关专题分析，不把本命全盘报告重写一遍。

## 专题应期

用户询问某个模块及时间时，依次建立：

1. 本命专题宫位及三方四正；
2. 大限同名宫位、命宫及三方四正叠入本命的位置；
3. 流年同名宫位、命宫及三方四正叠入本命的位置；
4. 生年、大限、流年四化分别进入哪一层的哪些宫位；
5. 现实状态决定结构可能表现为何种事件。

只有本命承接、大限放大、流年触发至少三层汇聚时，才称为“应期窗口”。应期表示某主题更容易发生、决定或承压，不表示事件必然发生。流月、流日仅在通过 [流月与流日补全](month-day-rules.md) 校验后缩小窗口；不得用月日信号反向制造年度事件。

## 现实落点

内部先确定一级宫位主题，再比较可能现实表现；默认只选最相关的少量表现，不罗列所有可能事件。例如田宅被触发首先表示住所、家庭结构或固定资产议题增强，可能表现为搬家、装修、置业、同居或家庭事务；只有额外证据明确汇聚时才提高其中某一种事件的等级。
