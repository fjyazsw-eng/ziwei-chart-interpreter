# 专题分析路径

只加载用户关心的路径；相关宫位必须放回三方四正与本命四化中理解。

只要专题含时间范围，先建立完整时间层事实表，再强制调用本命、大限、流年三层同名专题宫及各自三方四正。不能用“流年命宫叠本命专题宫”替代真正的流年专题宫。

## 事业与学业

官禄宫 → 官禄三方四正 → 命宫的能力与行动模式 → 财帛宫的变现方式 → 迁移宫的平台与环境 → 福德宫的持续动力 → 四化与运限。

输出职业环境、工作方式、优势、瓶颈、适合的能力建设。没有行业级证据时，不列唯一职业。

## 财务

财帛宫 → 命财官迁主轴 → 田宅宫 → 福德宫的安全感和消费动力 → 禄忌与煞曜 → 当前运限。

区分赚钱方式、现金流体验、守成方式和风险偏好。不得预测收益、资产数字或给投资指令。

## 感情与婚姻

夫妻宫 → 夫妻三方四正（夫妻、官禄、迁移、福德）→ 命宫互动方式 → 交友宫环境 → 四化与运限。

输出关系需求、沟通模式、容易出现的张力及改善条件。不得由单一煞忌断离婚、外遇或配偶遭遇。

## 人际与合作

交友宫 → 交友三方四正 → 命宫 → 兄弟宫 → 官禄宫 → 四化与当前运限。

区分私人关系、同辈支持、职场合作和资源网络。

## 居住与家庭

田宅宫 → 田宅三方四正 → 父母、夫妻、子女相关结构 → 迁移宫 → 运限。

空宫必须借对宫及三方判断，不能解释成“没有房产”或“没有家庭缘”。

## 健康与压力

疾厄宫 → 疾厄三方四正 → 命宫与福德宫 → 煞忌 → 运限。

仅描述压力模式、生活管理倾向和需要留意的宽泛领域。不得诊断疾病、推断寿命或建议停止医疗。

## 整体初读

输出精简的全盘基线报告：

1. 资料完整度与采用口径；
2. 三条核心结构及总体机会、代价和注意点；
3. 性格、行动方式、内在需求与压力反应；
4. 两条主要优势与两条长期课题；
5. 十二宫各一条简析；空宫必须结合对宫和三方，不写成“没有”；
6. 当前所处大限主题及最近的高关注年份；
7. 最值得继续深入的主题。

十二宫简析每宫只回答“该领域的基本模式、优势或注意点”，不复述完整星表，不把全盘写成十二篇星曜百科。

只有用户明确要求整体、综合、全盘或十二宫时才进入本路径。用户只是上传命盘时使用 L0 接盘模式，不自动执行整体初读。

## 专题应期

用户询问某个模块及时间时，依次建立：

1. 本命专题宫位及三方四正；
2. 大限同名宫位、命宫及三方四正叠入本命的位置；
3. 流年同名宫位、命宫及三方四正叠入本命的位置；
4. 生年、大限、流年四化分别进入哪一层的哪些宫位；
5. 现实状态决定结构可能表现为何种事件。

只有本命承接、大限放大、流年触发至少三层汇聚时，才称为“应期窗口”。应期表示某主题更容易发生、决定或承压，不表示事件必然发生。只给软件资料能支持的年份范围；没有流月盘时不缩小到月份。

## 现实落点

先输出一级宫位主题，再列多个可能现实表现。例如田宅被触发首先表示住所、家庭结构或固定资产议题增强，可能表现为搬家、装修、置业、同居或家庭事务；只有额外证据明确汇聚时才提高其中某一种事件的等级。
