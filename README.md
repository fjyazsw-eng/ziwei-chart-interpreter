# 赘肉君的紫微斗数私人顾问

一套面向已经有排盘软件的用户设计的紫微斗数解盘 Skill。

你提供文墨天机等软件导出的命盘 TXT、截图转写或结构化盘面，它负责核对盘面、建立证据链、分析本命结构，并结合大限与流年给出有依据的趋势和注意点。它不替你重新排盘，也不会为了把故事讲完整而补造盘面没有的数据。

## 仓库与安装地址

```text
https://github.com/fjyazsw-eng/ziwei-chart-interpreter
```

### 支持 GitHub Skill 的 AI

把上面的仓库地址发给 AI，并输入：

> 请从这个 GitHub 仓库安装 Skill。使用前完整读取 `SKILL.md`，并根据问题读取 `references` 目录中对应的规则文件。

### 不支持直接安装的 AI

1. 点击仓库页面绿色的 **Code** 按钮；
2. 选择 **Download ZIP**；
3. 解压后，将整个 `ziwei-chart-interpreter` 文件夹上传给 AI；
4. 告诉 AI 将该文件夹作为解盘规则使用，并先完整读取 `SKILL.md`。

只上传单独的 `SKILL.md` 也能运行基本流程，但完整文件夹还包含输入校验、证据规则、专题路径和运限推导规则，效果更完整。

## 三步开始使用

1. 从排盘软件导出完整命盘 TXT；
2. 将 TXT 发给已经安装本 Skill 的 AI；
3. 直接说明要做全盘分析，或者指定事业、感情、财运、家庭、迁移、健康、大限、流年等专题。

推荐的首次提问：

> 请使用“赘肉君的紫微斗数私人顾问”解读这份软件导出的命盘。先核对数据，再分析整体格局、性格、优势、长期课题、十二宫简况和当前大限；请区分软件直出、确定性派生和结构推论，并用大白话表达。

## 它和普通直接问 AI 有什么不同

- **先核对再解读**：不把缺失字段当成已知事实；
- **固定证据链**：结论要能回到宫位、星曜、三方四正、四化与运限；
- **区分事实与推论**：软件直出、规则派生和现实推论分别标注；
- **运限分层处理**：先看本命，再看大限，最后看流年触发；
- **时间盘先算后断**：涉及年份时先生成完整大限、流年十二宫和三层叠宫表；
- **统一交互档位**：只交盘时简短确认，快速问题简答，专题问题标准分析，明确要求时才输出深度报告；
- **控制幻觉**：不重新排盘；流月、流日只在农历、斗君、闰月、边界和月日干支可校验时补全；
- **允许验证**：可以回推历史高关注年份，但不根据用户反馈倒推圆故事。

## 它能做什么

### 全盘基线报告

没有指定问题时，默认提供：

- 命主的整体人生结构与主要矛盾；
- 性格、行动方式、内在需求和压力反应；
- 主要优势、长期课题及吉凶注意点；
- 十二宫各一条简明分析；
- 当前大限主题与近期高关注年份；
- 最值得继续深入的专题。

### 专题分析

可以单独询问：

- 事业、职称、考试与学业；
- 财务模式与资源压力；
- 桃花、恋爱、婚姻与关系互动；
- 正缘画像、恋爱启动与适合投入的时间差异；
- 同事、人际、团队与合作；
- 家庭、住房、搬迁与外地发展；
- 健康压力与生活管理倾向；
- 某一年或一段时间的大限、流年、流月、流日趋势。

### 大限与流年应期

分析顺序固定为：

1. 本命是否具备相应结构；
2. 当前大限是否放大该主题；
3. 流年宫位是否触发该主题；
4. 生年、大限、流年四化落入哪些本命、大限和流年宫；
5. 现实状态决定它可能表现为什么事件。

只有本命、大限和流年多层汇聚时，才标记为应期窗口。应期表示某个主题更容易发生、决定或承压，不代表事件必然发生。

## 运限数据不完整怎么办

如果软件只给出大限或流年命宫干支，没有展开完整十二宫，Skill 会按固定宫序生成可追溯的运限叠宫表。

如果软件缺少大限或流年四化，但目标天干明确，且软件口径与内置十干四化表一致，可以补出相应四化，并同时标注：

- 本命落宫；
- 大限落宫；
- 流年落宫；
- 数据来自软件直出还是规则派生。

流月、流日若资料齐全，可按可校验的斗君与流日公式补全宫位，并由软件/历法工具给出的月干、日干补出十干四化。它不会继续补造流昌流曲、流羊陀、宫干飞化或自化路线；边界或闰月口径不明时会停止补全。

## 如何使用

### 1. 准备命盘

优先从排盘软件导出包含以下内容的 TXT：

- 十二宫名称、干支与星曜；
- 命宫、身宫；
- 星曜庙旺利陷；
- 生年四化与软件标注的自化；
- 大限起止年份、宫位和四化；
- 流年年份、命宫干支和四化。

不需要另外提供出生资料让 Skill 重新排盘。截图也可以使用，但文本通常更完整、更方便校验。

### 2. 上传文件并直接提问

全盘示例：

> 请根据这个软件导出的命盘做整体分析，包括性格、优势、长期课题、十二宫简析和当前大限。

专题示例：

> 看看2026年的工作与人际，说明本命、大限、流年宫位和四化是怎样共同支持结论的。

感情示例：

> 命主目前单身，请分析未来几年的桃花与婚姻窗口，不要把流年夫妻宫直接等同于结婚。

验证示例：

> 先独立分析2005—2020年的高关注年份，我之后再提供经历验证，不要根据反馈倒推圆故事。

### 3. 指定你想要的表达方式

可以要求：

- “只说大白话”；
- “一句话总结”；
- “展示分析过程让我验证”；
- “只分析工作，不展开其他宫位”；
- “先给结论，再给宫位和四化依据”。

## 解读原则

### 软件盘面优先

排盘文件是唯一的本命盘来源。Skill 不根据记忆纠正星曜，不用出生资料另排一张盘覆盖原盘。

### 三种信息严格区分

- **软件直出**：排盘软件明确给出的数据；
- **确定性派生**：由软件干支按照固定规则得到的运限宫位或四化；
- **结构推论**：多个盘面事实共同支持的现实倾向。

### 不用单星制造重大结论

重大判断需要宫位网络、三方四正、四化及运限共同支持。单颗吉星不能直接断富贵，单个化忌也不能直接断失败、疾病、破财或离婚。

### 吉凶同时说明条件

当机会与压力同时存在时，会分别说明：

- 有利条件是什么；
- 代价或阻力在哪里；
- 哪些现实做法有助于发挥优势；
- 当前结论的证据一致性是高、中还是低。

## 能力边界

- 传统术数只能提供结构、倾向和注意窗口，不是事实预测；
- 不诊断疾病、不推断寿命、不提供投资指令；
- 不保证某年一定结婚、升职、发财、搬家或生育；
- 没有流月数据时，不把年份判断伪装成具体月份；
- 没有通过流月流日校验时，不把日期判断伪装成精确应期；
- 用户提供的经历只用于验证，不用于强行圆回原结论。

## 隐私建议

命盘可能包含出生时间、地点等个人信息。公开分享测试案例前，建议删除姓名、精确地点、聊天截图及其他可识别信息。本仓库只存放通用解读规则，不应提交个人命盘。
